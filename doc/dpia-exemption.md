# DPIA Exemption Note — TeamsVote

**Last Updated:** _2026-01-26_

This note explains why a formal Data Protection Impact Assessment (DPIA) is not required for the use of **TeamsVote** under GDPR (Article 35, EU 2016/679).

---

## 1. Minimal Personal Data Processing

TeamsVote processes only the following personal data supplied by Microsoft Teams:

- Microsoft Teams username  
- Microsoft Teams user ID  
- Microsoft Teams meeting or group chat identifier

No sensitive data categories are processed.

---

## 2. Purpose Limitation

Personal data is processed solely to:

- enable real-time voting functionality within Teams  
- associate votes with the correct session and meeting/group chat

No secondary processing occurs.

---

## 3. Data Retention

- All session data is held **in-memory only**  
- Data is discarded automatically at the end of each voting session  
- No personal data is persisted, logged, or exported

---

## 4. Risk Assessment

Given that:

- Data is minimal and ephemeral  
- No profiling or behavioral tracking occurs  
- No sensitive categories are processed  
- Data is processed entirely within the EU (Render, Frankfurt, Germany)  

TeamsVote poses **low or negligible risk** to the rights and freedoms of data subjects.

---

## 5. Conclusion

Under Article 35 of GDPR, a full DPIA is **not required** for TeamsVote.
